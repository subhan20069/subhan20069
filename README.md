I care about correct numbers, clean screens and code that is easy to maintain.

## What I'm working on

**MA PLASTIC ERP** — a desktop HR & financial ERP for a manufacturing business.

| Module | What it covers |
| --- | --- |
| Accounts | Chart of accounts, cash and bank vouchers, journal vouchers, ledger, cash book, receivables, payables, trial balance, group balance, gross profit |
| Sales | Sale invoices, sale orders, counter sale, returns, customer and item-wise reports |
| Purchase | Purchase invoices, returns, suppliers, item, brand and supplier-wise reports |
| Inventory | Items, brands, stock reports and stock value |
| HR | Employees, attendance, leave and payroll |

Built with double-entry accounting at its core, so every report reads from the same posted journal entries.
